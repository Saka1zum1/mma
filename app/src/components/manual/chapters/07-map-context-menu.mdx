Right-clicking the map opens a context menu. Right-clicking _a location_ adds a section of actions for that location at the top, above the tools below.

## On a location

- **Copy Street View link.** Copies a Google Maps link aimed at that location's saved heading, pitch and zoom, with its tags carried on the URL. Shortened when Google's shortener answers.
- **Copy pano ID.** Copies the location's panorama ID.
- **Download panorama.** Stitches and saves the full panorama image.
- **Copy to map...** Copies the location into another map, picked by name.
- **Duplicate location.** Adds a copy at the same spot.
- **Delete location.**

## Anywhere on the map

- **Start measurement / End measurement.** Begins a distance measurement anchored at the clicked point, or ends an in-progress measurement. See <ChapterLink id="scoring" />.
- **Copy coordinates.** Copies the clicked point as `lat, lng` to the clipboard.
- **Select this country / Select this subdivision.** Selects everything inside the border containing the clicked point. Subdivisions need **Subdivision borders** enabled in Settings; higher border detail downloads on first use.
- **Delete this polygon.** Removes the polygon selection(s) covering the clicked point.
- **Set latitude/longitude anchors.** Draws a crosshair of latitude and longitude reference lines through the clicked point, useful for aligning locations.
- **Clear latitude/longitude anchors.** Removes those reference lines.
