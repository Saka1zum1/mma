Selection rules can be saved and reused across maps via the command palette. They are stored with your app settings, not tied to a single map.

- **Save current selections...** Names the active selection set and stores it.
- **Apply saved selection...** Re-applies a stored set to the current map.

## Portability

Because saved selections move between maps, tag rules are stored by tag _name_ (matched case-insensitively on apply). Selection types that cannot be made portable are excluded from saving: **Manual**, explicit ID lists, **Validation state**, and review progress. Polygons, filters, untagged/unpanned/pano-id rules, uncommitted, top/bottom K, duplicates, and composites all carry over. A rule that no longer applies to the map you apply it to - a tag name that doesn't exist there - is quietly dropped rather than failing the whole set.
