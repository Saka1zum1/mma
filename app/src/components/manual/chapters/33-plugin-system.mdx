Plugins extend <App /> with new tools and panels. A plugin can add a **sidebar** panel, a full-screen **modal**, or a **location panel** embedded in the location editor, and it has full access to the app's data and Street View tools. Some add nothing visible at all and only register extra enrichment fields.

<Img name="plugin-marketplace.png" caption="The plugin marketplace: Core (built-in) and Additional (downloadable) tabs." />

## The marketplace

Open it from the puzzle-piece icon in the bottom-right corner. It has two tabs:

- **Core.** The plugins built into <App />. Each card has an **Enable**/**Disable** button.
- **Additional.** Downloadable plugins from the online registry, with **Install**, **Enable**/**Disable**, an uninstall (trash) button, and an **Update** action when a newer version is available.

Cards carry small markers you can hover for an explanation: a flask for **experimental** plugins, and a wand for ones that only add data fields. A plugin that needs a newer version of <App /> than you have says so instead of offering to install.

Enabled plugins activate automatically whenever a map is open, and the enabled set is remembered between sessions.
