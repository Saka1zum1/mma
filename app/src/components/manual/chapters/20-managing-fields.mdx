The **Enrichment** dialog (the database icon in the editor header, beside the map name) holds one table covering every metadata field known to the map: whether to enrich it, and how it is defined.

## What you can edit

- **Enrich.** Whether this field is fetched when enrichment runs. See <ChapterLink id="enrichment" />.
- **Field key.** Rename a field. Renaming to an existing field's key **merges** them; on conflict you choose which field's values win. Both rename and merge report how many locations are affected and cannot be undone.
- **Label.** The display name shown in pickers and filters.
- **Type.** **Text**, **Number**, **Date/time**, **Month (YYYY-MM)**, **Enum**, or **Array**. Enum fields get a value editor where you list the allowed values and give each a display label; it can pre-fill the list from the values already on your locations.
- **Compare as.** How the field is compared during disambiguation: **Auto**, **Numeric**, **Circular** (with a wrap period such as 360 for degrees or 24 for hours), or **Categorical**.
- **Delete.** Removes the field and clears its values from every location. This cannot be undone.

Each field row shows a coverage icon indicating what percentage of locations have a value for it. Edits apply immediately - there is no Save button - and the destructive ones ask first.
