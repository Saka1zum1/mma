**Settings → Application → Data** is where your files live.

- **Open data folder.** Opens the application data folder in the OS file browser. See <ChapterLink id="first-run" /> for what is in it.
- **Change folder.** Moves your maps somewhere else, such as a larger drive or a synced location. You confirm the new path before anything moves, and **Reset to default** puts it back.

## Diagnostics

- **Stats for nerds.** An overlay (<Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>) showing version, counts, storage size, and live render statistics. The first thing to check when something feels slow.
- **FPS counter.** A lighter always-on frame counter, in **Settings → Advanced → Debug**.
- **Open log file.** Also in **Settings → Advanced → Debug**. Grab this when reporting a bug.
- **Custom CSS.** **Settings → Advanced** takes a stylesheet that is applied over the whole app, so you can restyle anything you can select.

<Note>

Back up before anything risky (bulk deletes, large imports, moving the data folder). The recommended backup is **Export** on the home screen, which writes every map to a single ZIP. See <ChapterLink id="bulk-backup" />.

</Note>
